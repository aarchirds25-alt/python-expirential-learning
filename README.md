# Tic Tac Toe Game Using Python 🎮

##  Project Overview

Tic Tac Toe is a classic two-player game played on a 3×3 grid. This project is developed using Python and allows users to play against another player or against the computer.

The game displays the board, accepts player moves, validates inputs, checks winning conditions, detects draws, and provides an option to restart the game.

##  Objectives

- Develop an interactive Tic Tac Toe game using Python.
- Implement a 3×3 game board.
- Validate player inputs and prevent invalid moves.
- Detect the winner or a draw.
- Provide player-versus-player and player-versus-computer modes.
- Allow users to restart the game after completion.

##  Features

- Simple and user-friendly interface.
- Two-player game mode.
- Player-versus-computer mode.
- Automatic winner detection.
- Draw detection.
- Input validation.
- Option to play again.
- Organized code using Python functions.

##  Technologies Used

- **Programming Language:** Python
- **Concepts:** Functions, Lists, Loops, Conditional Statements, Input Validation
- **Platform:** Python IDLE, VS Code, or any Python-supported environment

##  How to Run the Project

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in your code editor.
4. Open a terminal in the project folder.
5. Run the following command:

```
python tic_tac_toe.py
```

If your system uses `python3`, run:

```
python3 tic_tac_toe.py
```

## 🎮 How to Play

1. Start the game.
2. Select the desired game mode, if available.
3. The game board will be displayed.
4. Players take turns selecting an available position.
5. The game checks for a winning combination after every move.
6. The game announces the winner or declares a draw.
7. Choose to play again or exit the game.

##  Modules

### Module 1: Game Board and Player Input

Creates the game board, displays it, accepts player moves, and validates inputs.

### Module 2: Game Logic and Winner Detection

Checks rows, columns, and diagonals for a winner, detects draws, and handles computer moves.

### Module 3: Game Flow and Restart

Manages player turns, displays the final result, and allows users to start a new game.
